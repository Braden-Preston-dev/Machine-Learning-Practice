# Machine-Learning-Practice

A place to save my machine learning projects, big or small, to learn and practice these concepts.

## Structure

Each project lives in its own folder under `projects/`:

```
projects/
  _template/        # copy this to start a new project
  my-project/
    README.md       # goal, data, approach, results, what I learned
    ...             # notebooks, scripts, small datasets
```

## Adding a project

1. `cp -r projects/_template projects/<project-name>`
2. Fill in the project's `README.md`.
3. Add your code, notebooks and dependencies (e.g. `requirements.txt`).
4. Add a line to the index below.
